📌 About the Project

CampusFlow is a smart class management portal designed to bring essential academic information into one place. It helps students track assignments, monitor subject-wise attendance, and stay informed about class holidays.

The project was developed as part of the Object-Oriented Programming Using C++ (ITUCTT2) course for B.Tech Information Technology, Third Semester, at Guru Ghasidas Vishwavidyalaya.

❗ Problem Statement

Students often face difficulties managing academic information because it is scattered across messaging groups, announcements, and separate records.

- Assignment topics, formats, and deadlines can be difficult to find.
- Students may not know their attendance percentage for each subject.
- It can be difficult to determine whether attendance meets the 75% requirement or the applicable 65% medical-case threshold.
- Students need a clearer way to estimate how many classes they can miss without falling below the required attendance threshold.
- Holiday information and attendance records need to remain consistent.

💡 Our Solution

CampusFlow provides a centralized portal with separate functionality for the Class Representative (CR) and students.

👨‍🏫 Class Representative Dashboard

- Create and publish assignments.
- Specify the subject and topic.
- Set the assignment date and submission deadline.
- Specify the required submission format, such as a separate copy or stick file.
- Mark holidays so attendance cannot be recorded as present or absent for those dates.

🎓 Student Dashboard

- View all assigned assignments and their details.
- Mark assignments as completed.
- Mark daily attendance as present or absent for each subject.
- View subject-wise attendance summaries.
- Monitor attendance against the applicable threshold.
- Estimate how many additional classes may be missed while remaining above the required attendance percentage.

Attendance estimates are informational and should be checked against official institutional rules and records.

✨ Key Features

- 🔐 Role-based login for CR and students
- 📝 Centralized assignment management
- 📅 Assignment deadlines and submission formats
- 🏖️ Holiday management
- 📊 Subject-wise attendance tracking
- ✅ Assignment completion status
- 📈 Attendance threshold and class-absence estimates

🧠 Object-Oriented Programming Concepts

The project demonstrates practical applications of OOP concepts, including:

- Classes and Objects — represent users, assignments, and attendance records.
- Encapsulation — organize data and the operations that work on it.
- Abstraction — expose essential behavior while hiding implementation details.
- Inheritance — support related user types through shared structures.
- Polymorphism — allow common interfaces to support role-specific behavior.
- Operator Overloading — define meaningful comparisons between objects where appropriate.
