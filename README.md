## 📌 About the Project

CampusFlow is a smart class management portal that brings essential classroom information into one place. It helps students manage assignments, track subject-wise attendance, and stay informed about class holidays.

Developed as part of the **Object-Oriented Programming Using C++ (ITUCTT2)** course at **Guru Ghasidas Vishwavidyalaya**, this project demonstrates how software can solve everyday academic coordination problems.

## ❗ Problem Statement

Students often struggle because academic information is scattered across messaging groups, classroom announcements, and separate records.

- Assignment topics, formats, and deadlines can be difficult to find.
- Students may not know their attendance percentage for each subject.
- It can be difficult to determine whether they meet the **75% attendance requirement** or the applicable **65% medical-case threshold**.
- Students need to estimate how many more classes they can miss without falling below the applicable attendance requirement.
- Holidays must be accounted for correctly when recording attendance.

## 💡 Our Solution

CampusFlow provides a centralized portal with separate features for the Class Representative (CR) and students.

### 👨‍🏫 Class Representative Dashboard

- Create and publish assignments.
- Specify the subject and topic.
- Set the assigned date and submission deadline.
- Specify the submission format, such as a separate copy or stick file.
- Mark holidays so attendance cannot be recorded for those dates.

### 🎓 Student Dashboard

- View assignments and their details.
- Mark assignments as completed.
- Mark daily attendance as present or absent for each subject.
- View subject-wise attendance summaries.
- Monitor attendance against the applicable threshold.
- Estimate how many additional classes may be missed while maintaining the required attendance percentage.

*Attendance estimates are informational and should be checked against official institutional rules and records.*

## 🧠 Object-Oriented Programming Concepts

The project demonstrates the practical application of OOP concepts, including:

- **Classes and Objects** — represent users, assignments, and attendance records.
- **Encapsulation** — organize data and the operations that work on it.
- **Abstraction** — expose essential behavior while hiding implementation details.
- **Inheritance** — support related user types through shared structures.
- **Polymorphism** — allow common interfaces to support role-specific behavior.
- **Operator Overloading** — define meaningful comparisons between objects where appropriate.
